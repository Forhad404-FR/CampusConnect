# Screenshots

Screenshots are **not included yet**. They must be captured from the running app.
Save them in this folder using the file names below, then follow the steps in the main `README.md`.

## How to capture

1. Run `npm install` then `npm run dev` and open the printed address (usually http://localhost:5173).
2. Use a desktop-size browser window (about 1440 px wide). Optional: use your browser's Developer Tools device toolbar for a mobile shot.
3. Log in with the demo accounts shown on the Login page (**Demo access** panel).
4. Capture each screen:
   - Windows: `Win + Shift + S`
   - macOS: `Cmd + Shift + 4`
   - Browser: DevTools, press `Ctrl/Cmd + Shift + P`, run **Capture full size screenshot**
5. Save as PNG in `docs/screenshots/` with these names.

| File name | Page | Logged in as |
|---|---|---|
| `01-homepage.png` | `/` Home | none |
| `02-clubs.png` | `/clubs` | none |
| `03-event-details.png` | An event details page, e.g. "Intro to Web Development Workshop" | student |
| `04-student-dashboard.png` | `/student/dashboard` | student |
| `05-organizer-dashboard.png` | `/organizer/dashboard` | organizer |
| `06-attendance.png` | Participants page of "Intro to Web Development Workshop" | organizer |
| `07-admin-dashboard.png` | `/admin/dashboard` | admin |
| `08-event-approval.png` | `/admin/events` (Pending tab) | admin |
| `09-mobile-view.png` (optional) | Any page in a phone-width window | any |

Tip: use **Reset demo data** on the admin dashboard before capturing, so every screenshot shows the original sample data.
